## Scope decisions

The demo's centerpiece is an organic code city whose visible shortcut disappears after a real repair. Codex investigates and illustrates; Decisions helps assess a boundary; Strata checks its own architecture. Each action must have an observable result.

Do not expand into a general autonomous coding platform, a full architecture editor, or an unvalidated composite score. Do not label included Codex image generation as Image 2.5 without evidence of that backend.

Private fin remains a local development input. Use approved public data for publication; the synthetic fixture is available. Do not publish generated images of private structure without review. Keep API use within the user's $50 credit constraint and continue using the signed-in Codex route where verified.

If hook integration consumes its 45-minute window, preserve the working explicit checker and repair/rescan journey, state the limitation, and move to visual polish. If public hosting or recording slips, drop stretch work immediately. Feature work ends at 16:00 regardless.
